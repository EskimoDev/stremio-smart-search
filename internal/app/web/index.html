Prepare your title catalogue

Download title data directly from IMDb and build a compact local index. The first download can be a few hundred MB and take several minutes.

Starting…

2

Choose your Stremio app

Choose an app below to copy the correct local addon link and open it. In that app, go to Addons → Add addon, paste the link and choose Install.

Checking installed apps…

Install through Stremio Web ↗

The web option opens the install prompt. Use the same Stremio account as your desktop app to sync the addon. Your browser may ask permission for Stremio Web to connect to this computer.

3

Put Smart Search first (recommended)

Move Stremio Smart Search to the top of your addon order so its search results are easy to find. In dx.bi: Addons → Order & backup → move to the top → Save order. Other clients may use different reorder controls.

Moving only Smart Search keeps the other addons in their same relative order. It supplies search rows only, so your stream providers keep their existing order. Account addon order may sync to your other devices.

Try HOTD, interstelar or LOTR. Use the “Stremio + Smart Search” shortcut next time to start both together.

Local means local

The search engine receives no stream links, account passwords or watch history. It does not send search terms to an AI service. Posters and playback still use online providers.

Keep the helper running

This page can be closed. Smart Search keeps working quietly in the background. A local addon link belongs to this computer; it does not install the helper on a TV or phone.
