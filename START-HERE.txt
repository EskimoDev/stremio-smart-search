STREMIO SMART SEARCH — PREVIEW

1. Open Stremio Smart Search. A local setup page opens in your browser.
2. Click Prepare catalogue. The first download can be a few hundred MB.
3. Choose Stremio, dx.bi or Stremio Enhanced. The link is copied and the app opens.
   Open Addons > Add addon in that app, paste the link and choose Install.
   Or use Install through Stremio Web with the same account as your desktop app.
4. Search as usual. Try HOTD, interstelar or LOTR.

Next time, use the Stremio + Smart Search shortcut to start both together.
Portable users: run the executable with --launch to open Stremio too.

You may close the browser page. The helper stays available in the background.
To stop it, reopen settings and click Quit helper.

No API key, AI subscription, account login or programming tools are needed.
The title data download is separate from the software and is subject to IMDb's
personal/non-commercial dataset terms. See DATA.md.

This preview is unsigned. Platform approval prompts may appear. Read the
installation notes for the platform's verification status and limitations.

The local addon address works on the computer running this helper. Installing
it on your Stremio account does not install the helper on your other devices.
