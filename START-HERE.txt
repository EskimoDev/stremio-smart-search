STREMIO SMART SEARCH — 0.1.0-preview.4

1. Open Stremio Smart Search. A local setup page opens in your browser.
2. Choose Catalogue size, then Prepare catalogue. Standard is the new-setup default.
   The first download can be a few hundred MB, with the same source files for all sizes.
3. Choose Stremio, dx.bi or Stremio Enhanced. The link is copied and the app opens.
   Open Addons > Add addon in that app, paste the link and choose Install.
   Or use Install through Stremio Web with the same account as your desktop app.
4. Search as usual. Try HOTD, strangerthings or LOTR.

RECOMMENDED: PUT SMART SEARCH FIRST
Move Stremio Smart Search to the top of your addon order to see its results first.
In dx.bi: Addons > Order & backup > move Smart Search to the top > Save order.
Other clients may use different reorder controls. Moving only Smart Search
keeps the other addons in their same relative order and leaves their stream
providers unchanged. Account addon order may sync to your other devices.

WHY IT CAN FEEL FAST
Matching uses a local title index in your computer's memory, so it does not
wait for a remote search server or AI response. Artwork and playback still
use online providers, and total loading times depend on your setup.

CATALOGUE SIZE
Compact: up to 25,000 movies + 25,000 series, with at least 250 IMDb votes.
Standard: up to 100,000 movies + 100,000 series, with at least 25 votes.
Expanded: up to 250,000 movies + 250,000 series, with at least 5 votes.
Actual counts depend on qualifying titles. Larger sizes use more memory.
Compare measured usage: https://github.com/EskimoDev/stremio-smart-search/blob/main/docs/PERFORMANCE.md
To change size, select it and click Apply size & rebuild. The existing catalogue
keeps working while the replacement is prepared, and is kept if preparation fails.

STORAGE
The Storage card in settings shows disk and memory use. Change location... moves
the catalogue to another folder or drive. Uninstalling leaves the catalogue in
place; use Open folder first if you want to delete it.

Next time, use the Stremio + Smart Search shortcut to start both together.
Portable users: run the executable with --launch to open Stremio too.

You may close the browser page. The helper stays available in the background.
Smart Search rows only appear while it runs. To start it whenever you sign in,
turn on Start Smart Search when I sign in in settings (off by default).
To stop it, use the Quit Smart Search shortcut, or click Quit helper in settings
and click again to confirm.

No API key, AI subscription, account login or programming tools are needed.
The title data download is separate from the software and is subject to IMDb's
personal/non-commercial dataset terms. See DATA.md.

Builds are not developer-signed or notarized. Platform approval prompts may appear.
Platform guide: https://github.com/EskimoDev/stremio-smart-search/blob/main/docs/INSTALLATION.md
That guide labels its target version; check the filename for your version.
If your build shows Update automatically, new installations default to checks
every 2 days; existing catalogues stay manual until enabled. A routine download
is about 240 MB, plus about 520 MB weekly with alternative titles. Turn automatic
updates off in settings if you want manual downloads only. The public preview.3
has no automatic-update controls.

The local addon address works on the computer running this helper. Installing
it on your Stremio account does not install the helper on your other devices.
